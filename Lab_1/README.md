# Лабораторная работа №1

## Вариант 1

Пользователь вводит строку вида `число число число<endline>`. Числа передаются
от родительского процесса в дочерний через неименованный канал (pipe). Дочерний
процесс считает их сумму и записывает результат в файл. Числа имеют тип `int`.
Количество чисел может быть произвольным.

## Компиляция

cc -Wall -Wextra -o parent parent.c
cc -Wall -Wextra -o child  child.c

## Запуск

./parent

Программа ждёт две строки ввода:
Имя файла
число1 число2 ... числоN

Пример:

$ ./parent
out.txt
5 10 15

$ cat out.txt
30
